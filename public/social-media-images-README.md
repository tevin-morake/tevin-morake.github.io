# Social Media Preview Images

This folder contains the Open Graph and Twitter Card images for social media sharing.

## Required Images:

- `og-image.png` (1200x630) - Main Open Graph image for homepage
- `og-image-square.png` (1200x1200) - Square version for some platforms
- `twitter-image.png` (1200x630) - Twitter Card image
- `og-contact.png` (1200x630) - Contact page specific image
- `og-testimonials.png` (1200x630) - Testimonials page specific image

## Design Guidelines:

- Include your logo and name prominently
- Use consistent branding colors
- Ensure text is readable at small sizes
- Include relevant imagery that represents your work
- Follow platform-specific guidelines for text placement

## Tools for Creating Images:

- Canva (templates available for social media)
- Figma (design from scratch)
- Adobe Photoshop/Illustrator
- Online OG image generators

These images will be displayed when your website links are shared on social media platforms like Facebook, Twitter, LinkedIn, and others.
